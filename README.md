# Siza: Offline Emergency Voice AI 🌍🗣️

Welcome to the research field notes and blog repo for **Siza** an offline, voice-first emergency assistant tailored for South African languages (isiZulu, Sesotho, and English). 

Scanned the research poster and ended up here? Excellent. This repository holds the stories, architectural details, and cryptographic receipts that didn't fit on the poster.


## 🛠️ Key Highlights Inside
* **On-Device WASM Sandbox**: Visualizing how the ONNX quantized model runs entirely in-browser.
* **Differential Privacy (DP)**: Explaining why we inject Laplace noise ($\epsilon = 1.0$) to guarantee that *African voice data stays in Africa*, not on centralized cloud servers.
* **A Student's Journal**: Honest reflections of a University of the Free State student moving from theoretical code to community-centric partner.
